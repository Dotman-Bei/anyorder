Batch clearing in three steps

Each step is one call to the AnyOrder contract; clear and claim can come from any account.

Orders collect for a set time

placeBuy and placeSell add your order to the open batch and lock its funds.

Open batchplacing
  • placeBuy(limit, quantity)locks ETH
  • placeSell(limit, quantity)locks TKN
  • Bookpublic until close

One price clears the batch

Anyone calls clear once the batch ends; it picks the price that trades the most volume.

Arrival order

Transaction order cannot change your fill. A closed batch clears by limit price, and every filled order in it trades at one price set by the contract.

Only two exchange handlers hold Call

Only deposit_token and withdraw hold Call, so only they can call another contract or send ether. Clearing has no Ctx or caller effect; the only identity it reads is each order's recorded owner, used only for the final tie-breaks (owner address, then the owner's own order sequence), which decide at most 1 base unit per order.

ingots/clearing/src/select.feno uses clause
/// Chooses the uniform clearing price of a batch.
/// The candidates are the distinct limit prices. Among
/// them it maximises the matched volume min(demand,
/// supply), then minimises the imbalance |demand -
/// supply|, then takes the highest remaining price at
/// which demand is at least supply, or, if there is
/// none, the lowest remaining price. The result depends
/// only on the multiset of orders, never on their
/// position in `orders`.
pub fn select_price(_ orders: MemVec<Order>) -> Clearing

No uses clause: no Ctx, no storage, no Call. allocate has none either.

Evidence for the batch claims

Run each from the repository root; a check fails when its claim does not hold.

Terminalrepository root

  • $ fe test --filter sandwich

    The pool sandwich profits; under condition C the batch attacker nets {{rec:batch.attackerTokens}} and {{rec:batch.attackerWei}}; a one-sided buy moves the price.

  • $ fe test --filter permutation

    Shuffled arrival orders, in the clearing library and across owners on the contract, keep the price and every owner's totals.

  • $ python ref/clearing_ref.py --check

    The exact Python reference regenerates the test vectors and fails if the committed ones differ.

  • $ pnpm -C web local

    Starts Anvil, builds and deploys the contracts, seeds a cleared and an open batch, and serves the app.
